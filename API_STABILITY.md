# API stability — janusplot

**Policy.** This package follows
[Semantic Versioning](https://semver.org/) and the
[lifecycle](https://lifecycle.r-lib.org/articles/stages.html)
vocabulary for individual symbols.

## Stability stages

- **experimental** — may change in any release; every change is
  recorded in `NEWS.md`.
- **stable** — public API; breaking changes only at major-version
  bumps, with at least one minor version of overlap via
  `lifecycle::deprecate_warn()`.
- **superseded** — a better alternative exists; the symbol is kept
  working but is not extended.
- **deprecated** — scheduled for removal; emits a `lifecycle`
  deprecation and is removed after at least one minor version.

## Breaking-change policy

- Column renames in output tables are breaking and are listed in
  `NEWS.md`; 1.0.0 renamed `pvalue` to `association_p`.
- Changes to default argument values are breaking for callers who
  rely on defaults and are listed in `NEWS.md`; 1.0.0 changed the
  default cell encoding and the cell orientation.
- A deprecated symbol or argument warns for at least one minor release
  before it is removed.
